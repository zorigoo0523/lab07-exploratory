## Дүгнэлт (Хэсэг E)
Энэхүү сессийн явцад Couch Potato болон Saboteur аялалууд үр дүнтэй ажиллаж, оролтын хязгаарлалт болон API-ийн хариуг шалгахад тусалсан. UI түвшний согогуудыг Mozilla Firefox 154.0 хөтөч дээр гар аргаар оролт өгч ажиглах замаар илрүүлсэн. API түвшний согогийг curl ашиглан илрүүлж, хариуг текст файлд хадгалсан. Charter-аас гадуур дэлгэцийн харагдац болон тоолуурын уялдааг давхар ажигласан. Хайлтын нарийн тохируулгууд болон зарим нэмэлт урсгалууд дараагийн сессэд үлдсэн. Энгийн утгын шалгалт болон API статус кодын шалгалтыг Playwright автомат тестээр барьж авах боломжтой. Харин өнгөний тохиромж, үсгийн алдаа, харааны гажилт болон зарим зөрүүг хүний нүдээр харах нь илүү найдвартай. Иймд автомат тест ба хүний exploratory тестийг хослуулах нь чанарын баталгаанд хамгийн ашигтай.
